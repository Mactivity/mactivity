- **Apps with an old updater**, in Outdated Software: many Mac apps update themselves with a built-in updater called Sparkle, and older copies of it have known vulnerabilities. Mactivity looks inside the apps in your Applications folders and names any that carry one, with the vulnerabilities and an Open App button, since only the app's own update fixes it.
- **An old Homebrew**, in Outdated Software: Homebrew versions with known security problems are named, with the command that updates it.
- **Safer updates for Mactivity:** an update's signature is now checked before it's unpacked, and Mactivity only accepts an update list that's signed with the same key, release notes included.
- Both checks read only what's on your Mac, from a list that comes with Mactivity. Nothing is looked up online.
