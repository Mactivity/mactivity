- **Outdated Software**, in Checkup: what on your Mac needs updating for security. Homebrew's packages and apps, the Python, Node.js, Ruby and PHP versions kept by pyenv, nvm, fnm, Volta, rbenv, asdf and mise, and the Python and Ruby that come with macOS and Xcode. Each says why: known vulnerabilities, no more security fixes since a date, security fixes ending soon, or a newer version out.
- **Upgrade from Mactivity:** Homebrew packages upgrade with one click after you confirm, with what Homebrew will change listed first. A language version that's no longer supported gives you the command that moves you to a current one, since upgrading would stay on the old line.
- **Known vulnerabilities, if you turn it on:** Settings → Privacy can have Homebrew check its packages against OSV.dev, Google's open vulnerability database, once a day. Off by default. Homebrew sends each package's name, source address and version; Mactivity itself connects to nothing.
- **An alert** when something installed has a high or critical vulnerability, or a language version reaches its end of life: once for each package and version.
