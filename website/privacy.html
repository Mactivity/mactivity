Privacy

Everything Mactivity measures stays on this Mac. On its own, it talks to the network for exactly one thing. Two more, host-name lookups and the vulnerability check, happen only if you turn them on.

1. Update check

At most once a day, Mactivity downloads https://mactivity.app/appcast.xml to see whether a new version exists. The request carries the app's version, like any web request's user agent. Updates are signed; Mactivity installs only builds signed with our key.

2. Host names, only if you turn them on

Off by default. With Settings → Privacy → "Look up host names in Get Info" on, clicking Look Up Name next to a connection asks your DNS server for that one address's name. Nothing is looked up automatically.

3. Vulnerability check, only if you turn it on

Off by default. With Settings → Privacy → "Check Homebrew packages for known vulnerabilities" on, Mactivity asks Homebrew, once a day, to check the packages it installed. Homebrew sends each package's name, source address and version to OSV.dev, Google's open vulnerability database. Mactivity itself connects to nothing for this, and nothing about anything else on your Mac is sent.

When you click Upgrade in Outdated Software and confirm, Mactivity runs brew upgrade for you, which downloads the new versions from Homebrew, as it does when you run it yourself.

Everything else stays on your Mac

History lives in ~/Library/Application Support/Mactivity. There are no analytics, no crash reports, and no accounts. Deleting history in Settings deletes it.

What Mactivity reads from macOS's own log

For History → Notifications by app, Mactivity reads macOS's log every three hours for the lines that say a notification was delivered. It keeps which app sent it and when, never the title or the text. For Security → Unlocks, it reads when your Mac was unlocked and how. Both are read on your Mac and never sent anywhere.

This website

mactivity.app counts visits with Cloudflare Web Analytics: page views, the country, and the browser, with no cookies and nothing that identifies you. That's about the website only. The app itself sends nothing about which apps you use or how often.

Permissions Mactivity may ask for

Notifications, for alerts. Bluetooth, only to read accessory battery levels. Audio capture, requested only when you enable per-app volume, and used only to set each app's level. Full Disk Access, optional, so the storage map can see every folder and the Security page can list which apps have which permission and what Chrome and Edge extensions can reach. Those lists are read when the page shows, kept in memory and never sent. Mactivity changes nothing there, and programs it starts, such as Homebrew, don't inherit this access. Desktop, Documents, Downloads, and removable or network drives, only when you scan them in the storage map, to measure how much space they use; Mactivity doesn't read or change what's in your files. Accessibility, only when you first use Clean Keyboard, so it can hold back key presses while you wipe the keyboard; it looks only for the ⌃⌥K that unlocks it, records nothing, and stops listening when you unlock. Each is used for exactly that.
