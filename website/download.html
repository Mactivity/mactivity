One small download, signed with our Developer ID and checked by Apple’s notary service. Drag it to Applications and it settles into your menu bar. It’s free: no license key, no account.

Download Mactivity

Mactivity 1.10.0, about 17 MB. For Macs with Apple silicon, macOS 26 or later.

Homebrew users can run brew install --cask mactivity/tap/mactivity instead; it also installs the mactivity command.

Get set up

  1. Open the disk image and drag Mactivity onto the Applications folder.
  2. Open Mactivity from Applications. The first time, macOS asks whether to open an app from the internet; choose Open.
  3. Optional: for a storage map that sees every folder and a fuller Security page, add Mactivity under System Settings → Privacy & Security → Full Disk Access. Without it, macOS asks folder by folder, and anything you decline shows as “Not readable”.

Staying up to date

Mactivity checks for updates once a day and installs them when you agree. To check now, choose Mactivity → Check for Updates…. What changed in each version is on the changelog.

Good to know

  • Free and open source. No license key is needed. The code is on GitHub under the MIT license. Bought a license earlier? Nothing to do: the app no longer asks for a key.
  • Offline is fine. Mactivity never needs the internet; it only checks for updates.
  • Other accounts' and system processes can only be inspected or quit with the optional helper. They always count toward the totals.
  • Per-app volume is experimental and stays off unless you enable it in Settings → General.

Need a hand?

Open an issue on GitHub. Mention your Mac model and macOS version, and what happened just before the problem. Mactivity collects nothing on its own, so an issue is how we hear about it.
